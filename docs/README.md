# 📁 Dossier docs/
Documentation technique du projet **SamsungToolkitA7** pour le smartphone **Samsung Galaxy A7 2018 — SM‑A750FN/DS — Android 10 / OneUI 2.0**.

Ce dossier regroupe toutes les informations essentielles : spécifications, partitions, bootloader, ROMs et kernels.

- [x] **device-specs.md**  
  Spécifications techniques complètes du Galaxy A7 SM‑A750FN/DS  
  (SoC, GPU, RAM, radios, capteurs, bootloader, identité interne).

- [x] **partitions-map.md**  
  Cartographie des partitions OneUI 2.0  
  (system, vendor, odm, product, vbmeta, dtbo, modem, userdata, etc.).

- [x] **bootloader-notes.md**  
  Notes sur le bootloader Samsung  
  (Download Mode, verrouillage, dm‑verity, vbmeta, dtbo, Knox).

- [x] **roms-kernels-overview.md**  
  Vue d’ensemble des ROMs et kernels  
  (ROM stock OneUI 2.0, compatibilité GSI, kernel stock, kernel custom).

## ✔️ Objectif du dossier

Ce dossier fournit une base documentaire solide pour :

- comprendre l’architecture du device,  
- préparer des opérations de diagnostic,  
- manipuler les partitions,  
- travailler sur les images boot,  
- évaluer la compatibilité ROM / kernel / GSI,  
- documenter les comportements du bootloader.
