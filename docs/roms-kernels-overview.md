# ROMs & Kernels Overview — Galaxy A7 SM-A750FN/DS

## ROM Stock (Android 10 / OneUI 2.0)
- Base stable Samsung
- Partition vendor stricte
- SELinux enforcing
- Compatible avec kernels stock uniquement

## ROM Custom / GSI
- Compatibles : Android 10 / 11 / 12
- Vendor strict → bugs possibles (caméra, radio)
- Nécessite vbmeta patché

## Kernels
### Stock Kernel
- Version : 4.4.x
- Stable, optimisé Samsung

### Custom Kernel
- Permet :
  - Root avancé
  - Modules supplémentaires
  - Optimisations CPU/GPU
- Requiert :
  - dtbo compatible
  - vbmeta patché
