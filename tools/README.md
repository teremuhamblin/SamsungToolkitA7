# tools/ — SamsungToolkitA7
Dossier regroupant les outils techniques pour manipuler le Samsung Galaxy A7 2018 (SM‑A750FN/DS).  
Inclut les utilitaires pour Odin Linux, les partitions, et les images boot.

## Contenu
- **odin-linux/** — Notes et outils pour Heimdall / Odin Linux.
- **partition-tools/** — Scripts pour analyser et vérifier les partitions.
- **boot-tools/** — Scripts pour extraire et reconstruire boot.img.

## Objectifs
- Fournir des outils fiables pour l’analyse système.
- Automatiser les opérations critiques (dump, vérification, extraction).
- Assurer une base technique pour le développement et le flash.
