# diagnostics/ — SamsungToolkitA7
Dossier dédié aux diagnostics du Samsung Galaxy A7 2018 (SM‑A750FN/DS).  
Inclut les scripts de collecte de logs, de vérification des capteurs, ainsi qu’un rapport système détaillé.

## Contenu
- **collect-logs.sh** — Collecte complète des logs système (logcat, dmesg, events).
- **sensors-check.sh** — Vérification des capteurs matériels via Termux/ADB.
- **system-report.md** — Rapport système détaillé (structure, infos, commandes utiles).

## Objectifs
- Fournir des outils fiables pour analyser le comportement du système.
- Identifier les erreurs HAL, vendor, kernel ou framework.
- Aider au debug des ROM, kernels, recoveries et GSI.
