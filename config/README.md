# configs/ — SamsungToolkitA7
Dossier regroupant les configurations, listes recommandées et notes techniques pour le Samsung Galaxy A7 2018 (SM‑A750FN/DS).  
Inclut les GSI compatibles, les modules Magisk recommandés, ainsi qu’une checklist sécurité.

## Contenu
- **gsi-recommended-list.md** — Liste des GSI compatibles et stables.
- **magisk-modules-notes.md** — Notes sur les modules Magisk recommandés / à éviter.
- **safety-checklist.md** — Checklist sécurité pour éviter les brick / pertes IMEI.

## Objectifs
- Fournir des configurations fiables pour ROM, GSI et modules.
- Documenter les risques et bonnes pratiques.
- Assurer une base technique pour un usage sécurisé du device.
