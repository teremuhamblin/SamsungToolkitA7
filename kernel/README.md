# kernel/ — SamsungToolkitA7
Dossier dédié au kernel du Samsung Galaxy A7 2018 (SM‑A750FN/DS).  
Il regroupe les notes techniques sur le kernel stock Samsung, les kernels customs compatibles, ainsi qu’un script d’exemple pour la compilation.

## Contenu
- **KERNEL_STOCK_NOTES.md** — Informations sur le kernel stock (3.18 modifié Samsung).
- **KERNEL_CUSTOM_NOTES.md** — Notes sur les kernels customs, limitations, compatibilité.
- **build/example-kernel-build.sh** — Script de build (template).

## Objectifs
- Documenter le fonctionnement du kernel stock.
- Identifier les contraintes pour les kernels customs.
- Fournir une base pour la compilation ou la modification du kernel.
